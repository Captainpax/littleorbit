# Question writing charter

Write one concrete, conversational question at a time. A useful prompt gives both partners
room for different answers without implying that one answer is healthier, kinder, or more
committed. Prefer ordinary moments, shared discovery, imagination, values, and memories over
abstract compatibility tests.

Interaction format must serve the idea. Choices should be plausible and distinct. Free text
should invite a bounded story or reflection. Partner-guess questions first ask each person for
their own choice; the application separately collects the private guess.

Changing options, punctuation, or interaction format does not create a new concept. Give every
question a stable concept family that describes the underlying conversation.
