# Contributors

Little Orbit began as a learning project by Pax to build a useful couples app that stays free for everyone. Every contribution is credited through Git history and GitHub's contributor graph.

## Ways to contribute

- Report a reproducible bug or privacy concern.
- Add or review safe questions for the curated fallback bank.
- Improve Android accessibility, offline behavior, or device compatibility.
- Strengthen the Python service, website, deployment guides, or translations.
- Review documentation from the perspective of someone learning the stack.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request and follow the [Code of Conduct](CODE_OF_CONDUCT.md). Never include real relationship data, access tokens, email addresses, or precise locations in an issue or fixture.
