# Little Orbit 1.0.0-rc.17

## Published prerelease

RC17 is the current signed release candidate. Phone and Wear downloads are hosted by the Little Orbit API with resumable byte ranges and mirrored in the matching GitHub prerelease. It remains a test release while the complete physical-device and external-service gates stay open.

## What changed

- Stopped **Save now**, autosave, and repeated create actions from producing another Our Space document. The phone keeps one create operation in flight, and the API recovers a recently saved exact document when an older client loses its local identity.
- Re-armed consented nearby-time collection after sign-in and every signed-in app start. Opening a paired Home or setup screen reconciles local permissions with both server consent states, and the visible five-minute service now recovers after Android reclaims its process.
- Corrected nearby freshness so it advances only to the newest sample time supported by both phones. One phone continuing alone now produces an honest stale state instead of “updated recently.”
- Simplified Home, the details screen, the home widget, Wear launcher, tile, and complication to lead with estimated nearby time. Pairing age and a manually chosen relationship start are no longer shown as together-time.
- Retained fully self-hosted notifications and authenticated first-party HTTPS/WSS traffic. RC17 adds no Firebase or hosted push service.

RC17 cannot reconstruct hours for which both phones did not provide confident nearby samples. After both partners install RC17, each phone must retain foreground and background location permission and the shared nearby-time setting; the estimate grows after two confident paired observations.
