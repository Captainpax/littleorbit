# Little Orbit 1.0.0-rc.5

RC5 replaced the quiz scaffold with a stable five-question daily flow and connected the global AI/curated question pipeline to the Android experience.

## Changes

- Presents one focused question at a time with typed controls for single choice, multiple choice, free text, partner guessing, and weighted choices.
- Saves private drafts, adds Review and Finish, and reveals answers only after both people finish all five.
- Adds seven-day catch-up, 30-day history visibility, queued custom couple questions, mutual intimacy filtering, and immediate question reports.
- Publishes validated global AI pools with quarantine and curated-bank fallback.
- Activates minimum phone version code 5 after the release became available.
