# Little Orbit 1.0.0-rc.10.1

RC10.1 is a focused correction for installing the self-hosted Wear companion from the
phone.

## Changes

- Corrects the RC10 Wear artifact mismatch with a new immutable Wear APK whose manifest
  contains the published version code 10.
- Updates Kadb to 2.1.4 and proves its lazy ADB connection with an authenticated command
  before reading watch properties.
- Tracks Android 17 DNS-SD service updates, loss, IPv4 selection, network identity, and
  post-pair port rotation while retaining the serialized fallback on older Android.
- Bundles Conscrypt 2.6.0 for the public TLS exporter and excludes HiddenApiBypass.
- Installs the verified APK through an explicit package session so write and commit have
  separate completion signals.
- Uses privacy-safe stage codes and discards raw endpoints, codes, fingerprints, and
  transport exception messages.
- Generates one signed release manifest from the phone and Wear modules' separate Gradle
  metadata, preventing one module's version code from being copied into the other.
- Keeps the active compatibility floor at phone version code 6; RC10.1 is optional and
  has no enforcement time.
