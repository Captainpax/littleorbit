# Little Orbit 1.0.0-rc.11.1

RC11.1 is a corrective rebuild of RC11. It preserves the Our Space, Markdown, attachment, and Smooch work and repairs the update path found during a real upgrade test.

## Changes

- Bounds the in-app release summary to eight lines so **Update**, **Later**, and the manual-download fallback stay reachable on small screens.
- Publishes concise plain-language metadata to the Android updater and RSS/site history while keeping the complete release record in this repository and on GitHub.
- Increments both phone and Wear package versions so every hosted artifact remains immutable.
