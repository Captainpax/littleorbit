# Little Orbit 1.0.0-rc.12.1

RC12.1 makes shared documents preview-first, renders authorized images where they were inserted, and replaces account-wide Smooch polling with self-hosted per-device partner notifications.

## Changes

- Opens existing documents in Markdown preview and uses one clear **Edit** / **Done editing** action instead of a segmented toggle.
- Renders only server-authorized `attachment://` images inline after exact size and SHA-256 verification. Sanitized GIFs animate on device; tapping an inline image opens the same private verified preview path.
- Keeps raw HTML inert and remote images blocked so opening a document cannot silently contact another host.
- Stores notification preferences with the account for Smooches, document editing, daily quizzes, countdowns, and weekly summaries, while Android permission and channel state remain per installation.
- Delivers Smooch and document-edit events independently to each registered phone. A content-free foreground WebSocket hint requests an immediate fetch; WorkManager supplies the durable background fallback.
- Sends one document-edit alert for the first accepted change, cools down for 30 minutes per document/editor, and skips the alert while the partner already views the document.
- Uses generic public lock-screen text for partner alerts and exposes content-free notification diagnostics in Settings.
- Adds shared cosmic fades and content reveals that honor the system's reduced-motion setting.
- Repairs Android 10 Markdown compatibility and registers mobile Hilt workers with WorkManager, defects found by the minimum-SDK emulator gate.
