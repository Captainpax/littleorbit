# Little Orbit 1.0.0-rc.6

RC6 makes the dashboard’s central time values honest and distinct. A mutually accepted relationship date now drives the relationship-age headline, while background location produces a separately labelled nearby-time estimate.

## Phone

- Keeps content clear of status bars, display cutouts, navigation controls, and the keyboard across every activity.
- Adds a seven-day start-date proposal with explicit partner acceptance, decline, cancellation, idempotent retry, and stale-state handling.
- Guides notification, precise location, background location, mutual server consent, and connected-watch setup from More.
- Rejects stale fixes and uses balanced 15-minute collection only while local permission and server consent allow it.
- Prevents the first quiz status poll from producing a false notification.

## Widget and Wear OS

- Stores relationship date, nearby estimate, nearby process time, countdown, and cache sync time as separate fields.
- Adds widget refresh and sign-out clearing with an honest stale state.
- Publishes a v2 Wear Data Layer record while keeping the v1 path for one compatibility release.
- Updates the Wear screen, tile, and complication to show relationship age and nearby time without mixing their meaning.
- Adds a first-party Wear APK endpoint and guided wireless-ADB installer with package, version, byte count, SHA-256, watch type, and signer verification.

## Server and operations

- Recomputes the rolling 24-hour raw window with deterministic one-to-one matching and confident bounded intervals.
- Deletes both partners’ raw coordinates when either person opts out and rejects uploads without mutual consent.
- Retains coordinate-free nearby history for 30 days and prunes start-date retry records after 30 days and resolved proposals after 90 days.
- Repairs the original mutable-model bootstrap migration so a clean database can reach Alembic head reproducibly.
- Requires complete phone and Wear metadata for RC6 publication and serves both artifacts with verified HEAD and byte-range behavior.
