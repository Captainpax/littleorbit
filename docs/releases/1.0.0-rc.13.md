# Little Orbit 1.0.0-rc.13

RC13 makes countdowns feel like calendar moments, completes quiz transition alerts, tightens generated-question typography, and changes avatars into a small thing each partner chooses for the other.

## Changes

- Replaces typed UTC countdown entry with a concept-led timeline, upcoming and past sections, an expanded bottom-sheet editor, date and time pickers, timed or all-day moments, and explicit IANA timezone handling.
- Adds private per-partner reminder choices for the event time, one hour, one day, and one week before. All-day reminders use 9:00 AM in the event timezone, and Android reconciles alarms after sync, reboot, app replacement, clock changes, and timezone changes.
- Adds a one-way **Add to calendar** action through Android's calendar contract. The person chooses the calendar and approves the copy; Little Orbit does not request Google credentials or claim two-way synchronization.
- Sends self-hosted per-device alerts when a countdown is created or rescheduled, when a daily quiz is available, when a partner finishes, and when shared results are ready. Events contain bounded identifiers, titles, or dates and never quiz answers or countdown notes.
- Removes the old separate quiz-status poller so one notification ledger owns Smooch, document, countdown, and quiz delivery. A missing daily pool can delay its own alert without blocking unrelated pending events.
- Replaces compressed 1–5 quiz labels with responsive choices and rejects generated questions containing tabs, line breaks, non-breaking spaces, control characters, leading or trailing space, or repeated horizontal space.
- Makes avatars relationship-scoped and partner-assigned. Your avatar is read-only because your partner chooses it; only your partner's avatar exposes choose, crop, and remove controls.
- Deliberately clears the old self-selected profile photos during migration `0016` because silently treating them as partner-selected would misstate ownership.
- Repairs the API 29 countdown crash found by the minimum-SDK device gate and expands the bottom sheet so all editor controls remain reachable on phones and tablets.
