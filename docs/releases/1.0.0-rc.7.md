# Little Orbit 1.0.0-rc.7

RC7 is a narrow follow-up discovered during the RC6 device gate. It keeps the RC6 phone, server, location, widget, and Wear behavior and corrects the Wear launcher fallback on round screens.

## Changes

- Fits the logo, relationship date, nearby estimate, and stale status inside the round safe area.
- Keeps the launcher vertically scrollable for larger accessibility text and smaller watches.
- Increases both application version codes to 7 so every published APK remains immutable and upgrade-safe.
- Keeps the active minimum supported phone version at code 6; RC7 remains an optional update.
