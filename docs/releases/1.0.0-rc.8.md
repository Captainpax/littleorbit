# Little Orbit 1.0.0-rc.8

RC8 brings the phone home and Wear launcher closer to the visual concept, removes the computer-script requirement from normal watch installation, and adds a public release history.

## Changes

- Makes nearby time the primary home estimate, keeps agreed relationship age as secondary context, and adds two photo-capable planets, filled icon cards, the live quiz prompt, chevrons, and compact icon navigation.
- Adds private square profile photos. The server strips metadata and stores bounded WebP variants; only the owner and current partner can fetch them. Phone and Wear launcher caches are private and use initials when no image exists.
- Adds a phone-hosted wireless-ADB Wear installer with first-party artifact and signer verification, local endpoint discovery, manual fallback, encrypted remembered authorization, device/SDK/downgrade checks, and an explicit old-security-patch warning.
- Replaces the public PowerShell watch installer with an Android App Link while keeping the raw verified Wear APK for recovery.
- Adds immutable release history, `/patch-notes`, and RSS 2.0 at `/patch-notes.xml`.
- Expands every major-system agent guide to require a full Markdown inventory and roadmap review for every update.
- Keeps the active compatibility floor at phone version code 6; RC8 is optional.
