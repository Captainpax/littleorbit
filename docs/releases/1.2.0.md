# Little Orbit 1.2.0

Status: published on 2026-09-21

Little Orbit 1.2.0 deepens daily quizzes without making them personal-data training material. After a shared reveal, each partner can privately rate an eligible global question with one to five stars, up to three fixed tags, and an optional consented review. Saturday learning uses only thresholded, sanitized global feedback; Sunday generation builds the following Monday-through-Sunday sets with a strict policy, 365-day semantic memory, and pinned local models.

Each partner can also choose the relationship name both people use for the other person. Names
are shared across authorized phone, notification, widget, and managed-Wear surfaces without
changing account identity; contact-shaped values are rejected and unpairing erases them.

The browser administrator panel is removed. A separate Java/XML Android application, [Big Orbit](https://github.com/Captainpax/big-orbit), provides device-bound enrollment, an actionable moderation inbox, service health, registration and bounded account/session controls, privacy-safe quiz intelligence, AI observability, typed operations, backup status, security events, and per-device generic notifications. Administrators still cannot inspect answers, notes, relationship history, precise locations, or exports.

Big Orbit 1.0.0 uses version code 2. Its signed code-1 candidate was discarded before
publication after the exact minified APK exposed a WorkManager Room-constructor crash; code 2
adds a physical/emulator cold-launch gate and is signed by Big Orbit's independent certificate.

## Data and operations changes

- Migration `0027` enables pgvector and adds private feedback, anonymous-retention, weekly aggregate, semantic concept, policy, run, reserve, and allowlisted-context records.
- Migration `0028` adds enrolled Big Orbit devices, key challenges, device-bound sessions, per-device alerts, typed jobs, and content-free backup evidence.
- Migration `0029` adds relationship-scoped partner names and bounded idempotency records.
- Linked feedback is editable for 30 days; attribution is then removed. Raw optional reviews are deleted after 90 days.
- Coordinated dumps exclude attributable feedback, feedback operations, anonymous raw reviews, raw coordinates, and collection-health snapshots.
- Daily encrypted backup, Tuesday non-destructive restore, and five-minute typed-job tasks are registered on the production host. One runner backup and restore drill passed with content-free evidence; the backup remained local because the owner waived the off-host gate until the replacement server is available.
