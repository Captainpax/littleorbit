# Little Orbit 1.0.0-rc.14

## Published prerelease

RC14 is the current signed release candidate. Phone and Wear downloads are hosted by the Little Orbit API with resumable byte ranges and mirrored in the matching GitHub prerelease. It remains a test release while the external-service and complete physical-device gates stay open.

## What changed

- Reworked the Android shell with independent Home, Settings, and App updates destinations, phone drawer gestures, a bounded tablet rail, and contextual right-side actions only where they are useful.
- Added resumable setup guidance, clearer pairing and account recovery states, themed dialogs, accessibility improvements, reduced-motion-aware transitions, and consistent cosmic components.
- Hardened quizzes, countdowns, partner-assigned avatars, Smooches, together-time estimates, widgets, and Wear relationship purging.
- Made Our Space preview-first, cursor-stable, process-restorable, and safe for CommonMark/GFM plus authorized inline attachments. Fixed an image-authorization timing race and concurrent private-cache directory creation. The foreground library now refreshes every five seconds, ignores identical snapshots, and gives the partner a content-free wake event when a document is created, so documents created on the other phone no longer remain hidden behind a stale library.
- Added PostgreSQL-backed abuse limits, stronger reset and pairing serialization, administrator MFA replacement rules, live WebSocket reauthorization, structured relationship invalidation, bounded diagnostics, isolated media processing, and coordinated encrypted backups.
- Added installation-scoped partner alerts with content-free WSS and optional FCM wake signals. The published APK has no Firebase public build settings, so first-party polling remains the active transport.
- Scheduled raw-location deletion five minutes before the absolute 24-hour ceiling and added an independent hard-ceiling purge for legacy or damaged expiry metadata.

## Verified so far

Automated Python, web, Android unit, lint, and instrumentation checks pass. The paired smoke flow passes on API 29, API 30, API 36 phone, wide API 36 tablet, and a round API 34 Wear emulator. A dedicated two-account note smoke proves partner listing, bidirectional live edits, disconnect/reconnect catch-up, identical final revisions, notification cooldown, and automatic foreground-library discovery. A signed RC13 phone APK upgraded directly to this exact candidate on API 36 and launched without a fatal error.

Promotion to 1.0 still requires Gmail credential rotation, owner MFA re-enrollment, Firebase setup and two-install notification checks, NPM TLS/HSTS validation, and the full physical two-phone, tablet, widget, and Pixel Watch journey. Direct ADB replacement proves artifact compatibility; the published in-app updater path remains part of that physical gate.
