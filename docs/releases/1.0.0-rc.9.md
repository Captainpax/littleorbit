# Little Orbit 1.0.0-rc.9

RC9 is a corrective release for the widget crash found while leaving a completed quiz and for the profile crop screen whose library action bar was hidden by Little Orbit's no-action-bar theme.

## Changes

- Replaces receiver-owned widget threads with unique WorkManager renders. Broadcast callbacks enqueue bounded work, database failures render an unavailable state, and repeated cache signals coalesce safely.
- Gives the shared quiz reveal an explicit completed state and a fixed **Done** action above bottom navigation. Done clears the quiz activity and returns to Home.
- Replaces the exported library crop activity with a non-exported Little Orbit screen that stays within system insets and always exposes **Cancel** and **Use photo**.
- Produces an exact 512-by-512 WebP crop in app-private cache, keeps approval explicit, bounds the upload read to 5 MiB, and removes the temporary file after use.
- Keeps the active compatibility floor at phone version code 6; RC9 is optional.
