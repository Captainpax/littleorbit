# Little Orbit 1.0.0-rc.4

RC4 moves the primary Android download from GitHub to Little Orbit's own API after a real mobile transfer repeatedly stalled at 99 percent.

- Version name: `1.0.0-rc.4`
- Version code: `4`
- Package: `com.littleorbit.mobile`
- Minimum Android: API 29
- Phone bytes: `15747217`
- Phone SHA-256: `94f6a8a6393d0a76680996dc8ee7274859969b0993bca99bece0d1a665bb69d6`
- Signing certificate SHA-256: `43e83a420c7496ce9121339ab5bd6b01a6357161a83a95042ace56855bd89337`

## Changes

- Serves the phone APK from a stable, versioned Little Orbit API endpoint.
- Supports `HEAD` and HTTP byte ranges so interrupted downloads can resume.
- Checks stored size and SHA-256 before publication and every download response.
- Uses an exact content length, checksum header, digest ETag, attachment filename, and immutable caching.
- Updates Android to trust the matching first-party endpoint while retaining the canonical GitHub pattern for historical metadata.
- Keeps GitHub as a signed-binary recovery mirror and public source history.

## Upgrade note

RC3 trusted only GitHub APK URLs. Install RC4 once from the Little Orbit download page; RC4 and later can use first-party downloads through the in-app updater.
