# Little Orbit 1.0.0

Little Orbit 1.0 is the first free, open, self-hosted release for couples. It includes daily quizzes, Smooches, shared Markdown documents and private attachments, countdowns, estimated nearby time, partner-assigned avatars, a home widget, a Wear OS companion, first-party APK updates, and a public website with no paywalls or advertising.

## Nearby-time repair

- Evaluates every chronological observation instead of discarding unmatched readings when phones report at different rates.
- Requires fresh evidence from both members and bounds counted intervals, sample skew, and live display projection to five minutes.
- Shows only estimated nearby duration on the Together Time screen. Relationship age remains metadata and is not presented as measured time spent together.
- Updates the visible seconds with Android's monotonic clock until the server's explicit deadline, then freezes and explains the current nearby, confirming, apart, inaccurate, waiting, or stale state.
- Uses a two-minute visible foreground cadence with a 15-minute recovery fallback, encrypted offline batching, exact relationship scoping, retry-safe sample IDs, and immediate consent/permission cleanup.
- Keeps widget and Wear displays on authoritative observed totals so passive surfaces cannot continue counting after evidence expires.

## Reliability and compatibility

- Clears legacy unscoped queued coordinates during the Room 5 migration instead of risking upload into a later relationship.
- Keeps samples queued during offline, throttled, or temporary service failures and isolates terminal poison rows so one bad sample cannot block later valid samples.
- Retires legacy v1/v2 together-time writers with `410 Gone`; current clients use the v3 contract.
- Preserves corrections during rolling recomputation and labels older estimate provenance honestly.
- Continues the RC17 retry-safe shared-document creation fix so autosave and repeated Save actions keep one document identity.
