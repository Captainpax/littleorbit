# Little Orbit 1.0.0-rc.11

RC11 brings shared notes and Smooches into the visual and interaction system established by the concept art.

## Changes

- Rebuilds Notes as **Our Space**, a searchable document library that opens into a focused editor with Edit/Preview tabs, formatting helpers, presence, archive recovery, and explicit conflict choices.
- Uses one persistent note WebSocket for snapshots, presence, operations, acknowledgements, and reconnect. Server acknowledgements patch only the changed range so Android preserves the cursor and selection while typing.
- Adds CommonMark and GitHub-style tables, task lists, strikethrough, and links. Raw HTML is displayed as text and remote image syntax becomes a deliberate link instead of loading third-party content automatically.
- Adds resumable current-couple attachments for JPEG, PNG, WebP, GIF, PDF, TXT/Markdown, MP3, M4A, Ogg, MP4, and WebM. Files are limited to 100 MiB each and 2 GiB per couple.
- Keeps uploads private until ClamAV reports them clean and a type-specific metadata-removal pass succeeds. Android verifies the sanitized digest before preview or **Keep offline**.
- Adds confirmed attachment deletion, scan-state refresh, archived-note file cleanup, aggregate owner-console scan counts, and paired database/attachment backup guidance.
- Moves Smooches into the center of the five-tab shell with a focused emoji picker, partner name, remaining hourly allowance, orbit-pulse confirmation, current-week memory, and historical weeks without rankings.
- Publishes the approved RC11 Our Space and Smooch concept studies in the repository and website showcase.
- Keeps the active compatibility floor at phone version code 6; RC11 is optional and has no enforcement time.
