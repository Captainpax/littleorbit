# Little Orbit 1.0.0-rc.2

This signed release candidate fixes the Android sign-in experience for verified accounts that have not paired yet.

- Keeps the authenticated home state visible when shared couple data is not available yet, so pairing and member controls remain accessible.
- Clears phone, widget, watch, countdown, and queued-location data when the local account changes, signs out, is deleted, or unpairs.
- Adds the complete Room migration path used by the home-screen widget.
- Increases the phone and Wear OS `versionCode` to 2 for an in-place update from `1.0.0-rc.1`.
- Uses the existing Little Orbit release certificate and includes SHA-256 checksum sidecars.
