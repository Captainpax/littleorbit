# Little Orbit 1.0.0-rc.10

RC10 improves the daily reliability of Little Orbit and adds a small private way for partners to reach out.

## Changes

- Derives relationship age automatically from the confirmed pairing instant; the app no longer asks for a start date.
- Collects consented high-accuracy location about every five minutes in a visible foreground service, retains a 15-minute recovery job, and queues valid fixes while offline. Conservative two-sample proximity rules remain unchanged.
- Adds Smooches with nine fixed emoji, private notifications, five sends per rolling hour, encrypted short-lived offline delivery, Monday-to-Sunday totals, and private history across unpairing.
- Rebuilds Notes as a titled multi-note workspace with unique-account presence, 750 ms body debounce, idempotent metadata operations, explicit conflicts, archives, and seven-day undo.
- Adds first-launch opt-in for six-hour update metadata checks, once-per-process availability prompts, a persistent More status, and five-minute stalled-download detection. APK transfer still requires explicit approval.
- Hardens the phone-hosted Wear installer against stale DNS-SD callbacks, host/port mismatches, and the connection-port change that follows wireless-debug pairing.
- Starts the scheduled worker only after the API health check proves database migration is complete.
- Keeps the active compatibility floor at phone version code 6; RC10 is optional and has no enforcement time.
