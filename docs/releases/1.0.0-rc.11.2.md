# Little Orbit 1.0.0-rc.11.2

RC11.2 is a corrective rebuild of RC11.1. A clean RC10.1 update test downloaded and verified the self-hosted APK, reached the unknown-source permission gate, and then exposed an abandoned Android package session before the system installer appeared.

## Changes

- Close and sync the APK write stream before committing its `PackageInstaller.Session`.
- Keep the RC11 Our Space, Markdown, private attachment, and dedicated Smooch experiences.
- Keep the bounded in-app summary introduced in RC11.1; full notes remain available on the website and GitHub.

RC10.1 and RC11.1 cannot use this repair before replacing their already-running code. Install RC11.2 or later manually once; subsequent versions use the corrected package-session path.
