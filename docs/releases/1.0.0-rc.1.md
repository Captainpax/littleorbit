# Little Orbit 1.0.0-rc.1

This is the first signed Little Orbit release candidate for Android 10 and newer.

- Phone APK with quizzes, pairing, shared countdowns, notes, together-time, privacy controls, and the home-screen widget.
- Wear OS companion APK with the cached together-time view, tile, and complication.
- Both APKs use the documented Little Orbit release certificate and include SHA-256 checksum sidecars.
- The clients connect to `https://lil-orb.pax-kun.com`.

This is a prerelease for testing. The two-phone and Wear OS full-flow hardware gate remains open, so do not use it for real relationship data yet. Report security problems privately through [`../../SECURITY.md`](../../SECURITY.md).
