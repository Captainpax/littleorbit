# Little Orbit 1.0.0-rc.11.3

RC11.3 carries the RC11.2 package-session repair forward as a small successor release. Its purpose is to exercise the repaired updater from an installed RC11.2 client while keeping the complete Our Space and Smooch feature set.

## Changes

- Preserve the stream-closure fix before `PackageInstaller.Session.commit`.
- Advance phone and Wear version codes so RC11.2 can test a real in-place update.
- Document that RC10.1 and RC11.1 need one manual update before future automatic updates can work.

- Wear version code 14: `little-orbit-wear-1.0.0-rc.11.3.apk`, 14,133,466 bytes, SHA-256 `6d609669fd079ec179d9c39be01a3d9485392681a637c769b43cf5cdeab5641c`.

Both APKs pass Android v3 signature verification. RC11.3 remains a prerelease until the open physical-device, privacy, battery, legal, network-reservation, and restore gates in the roadmap pass.

An API 36 emulator running the signed RC11.2 build discovered RC11.3, downloaded and verified its self-hosted APK, opened Android's native update confirmation, and completed the in-place replacement to version code 15. Android recorded the application-owned session as committed and installed.
