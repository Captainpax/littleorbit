## Changes

- Adds public immutable release metadata and an administrator release form with version, size, signer, compatibility floor, and optional enforcement time.
- Adds daily and foreground release checks without background APK downloads.
- Downloads only after user action, then verifies GitHub authority, byte count, SHA-256, package, increasing version code, and the pinned Little Orbit signer before invoking Android's installer.
- Persists progress and safely resumes download, verification, permission, and install states after activity recreation or process death.
- Adds optional 24-hour deferral and an explicitly scheduled compatibility-only required-update gate.
- Rebuilds the phone shell, feature forms, widget, and Wear OS launcher around the navy, lavender, coral, and amber concept system.
- Adds Inter under the SIL Open Font License and keeps planet placeholders to initials or abstract shapes instead of adding profile-photo data.

RC2 users need one final manual install because RC2 predates the updater. RC3 and later builds can discover subsequent releases inside the app.
