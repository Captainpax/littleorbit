# Little Orbit 1.2.0 concept sheets

These are generated design concepts, not production screenshots. They establish the 1.2 cosmic visual direction while implementation remains constrained by Android accessibility, dynamic text, screen size, and native security flows.

- `little-orbit-quiz-feedback-concept.png` — post-reveal stars, fixed tags, optional consented review, and edit state in the Little Orbit phone app.
- `big-orbit-enrollment-concept.png` — password/MFA and Android Keystore device enrollment.
- `big-orbit-action-inbox-concept.png` — privacy-safe alerts, health, and typed operator actions.
- `big-orbit-quiz-intelligence-concept.png` — K-anonymous ratings, tags, and sanitized review themes.
- `big-orbit-ai-observatory-concept.png` — policy, model provenance, weekly runs, semantic memory, and safe context sources.

The sheets use simulated names, values, and operations data. No production account, relationship, review, location, or credential appears in them.
